An interactive, zero-dependency, single-file Web application designed for independent creators and digital merchants to plan, script, and preview **high-converting 15-second short videos** for **LINE VOOM**, **YouTube Shorts**, and **TikTok**.

Built to power decentralized, platform-proof customer acquisition pipelines.

---

## ✨ Key Features

- **⏱️ 15-Second Golden Ratio Timing**: Automatically breaks down your script into 0–3s (Hook), 3–12s (Core Value), and 12–15s (Call to Action / CTA).
- **📱 9:16 Real-time UI Preview**: Simulate how your captions and visual overlay will look on mobile screens before rendering video.
- **🎨 High-Impact Caption Styles**: Toggle between High-Contrast Yellow, LINE Classic Green, and Dark Subtitle overlays designed for silent mobile scrollers.
- **🔊 Browser-Native TTS Audio**: Test your script's rhythm, pacing, and word count using local Text-to-Speech audio preview.
- **🚀 Pre-Built High-Converting Templates**: Includes ready-to-use scripts for platform-proof marketing, comparative linguistics, and zero-cost digital asset monetization.
- **⚡ Zero Dependencies**: Pure HTML5, Tailwind CSS (via CDN), and Vanilla JavaScript in a single `index.html` file. Host anywhere for free!
